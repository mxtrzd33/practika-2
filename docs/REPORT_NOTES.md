# Материалы для демонстрации

## Тестовый набор

- `A`: зависимости `B`, `C`; транзитивно `D`, `E`.
- `B`: зависимость `D`.
- `C`: зависимости `D`, `E`.
- `E`: зависимость `A`, поэтому присутствует цикл.
- `F`: отдельная цепочка `F -> G`.
- `G`: зависимостей нет.

Примеры трёх пакетов для этапа 5: `A`, `B`, `F`.
Для каждого следует запустить приложение с соответствующим `package_name`
и сохранить полученные DOT/PNG. В тестовом режиме имена условные и не
являются реальными пакетами Alpine.

## Сравнение со штатными средствами

На Alpine Linux можно выполнить `apk info -R PACKAGE` для прямых
зависимостей и `apk info -r PACKAGE` для обратных. Сравнивать нужно
одинаковые версии и одинаковые подключённые репозитории. Возможные
расхождения: архитектура, версия индекса, виртуальные пакеты/provides,
ограничения версий, установленные пакеты против всех доступных пакетов.
