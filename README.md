# Вариант №25. Разработка CLI-инструмента визуализации графа зависимостей пакетов Alpine Linux

## 1. Тема работы

**Разработка командного интерфейса для анализа и визуализации графа зависимостей пакетов Alpine Linux.**

Программа предназначена для получения информации о зависимостях пакетов из репозитория Alpine Linux, построения графа прямых и транзитивных зависимостей, поиска обратных зависимостей и визуального представления полученной структуры.

## 2. Цель работы

Разработать консольное приложение (CLI-инструмент), позволяющее анализировать зависимости программных пакетов Alpine Linux, формировать ориентированный граф зависимостей и визуализировать его с помощью Graphviz.

В ходе работы необходимо освоить принципы обработки метаданных пакетного репозитория, построения графов, обхода графов в ширину, работы с конфигурационными файлами YAML и создания графических представлений структур данных.

## 3. Задачи работы

Для достижения поставленной цели необходимо выполнить следующие задачи:

1. Разработать CLI-интерфейс для управления программой.
2. Реализовать чтение параметров из YAML-конфигурации.
3. Обеспечить получение информации о пакетах и их зависимостях из файла APKINDEX репозитория Alpine Linux.
4. Реализовать построение ориентированного графа прямых и транзитивных зависимостей.
5. Реализовать обход графа в ширину (BFS) с защитой от повторного посещения вершин.
6. Добавить возможность фильтрации пакетов по заданной подстроке.
7. Реализовать поиск обратных зависимостей пакета.
8. Обеспечить экспорт графа в формат DOT.
9. Реализовать создание графического изображения графа с помощью Graphviz.
10. Разработать тестовый режим с использованием локального файла с данными о пакетах.
11. Провести модульное тестирование и проверить работу программы на реальных пакетах Alpine Linux.
12. Сравнить полученные результаты со штатными средствами Alpine Linux.

## 4. Используемые технологии

В проекте используются следующие технологии и инструменты:

| Технология | Назначение |

| YAML | Хранение конфигурационных параметров |
| APKINDEX | Получение метаданных пакетов Alpine Linux |
| BFS | Обход графа зависимостей в ширину |

| DOT | Формат описания графов |

Для получения зависимостей из настоящего репозитория программа самостоятельно обрабатывает файл APKINDEX. Готовые менеджеры пакетов и сторонние пакетные менеджеры для извлечения зависимостей не используются.

## 5. Архитектура программы

Программа построена по модульному принципу. Каждый модуль отвечает за отдельную часть функциональности.

Основные компоненты:

- `main.py` — точка входа в приложение, обработка аргументов командной строки и запуск анализа.
- `config.py` — чтение и обработка YAML-конфигурации.
- `apk.py` — получение и обработка метаданных пакетов из APKINDEX.
- `graph.py` — построение графа зависимостей и обход графа.
- `reverse_dependencies.py` — поиск обратных зависимостей.
- `test_repository.py` — работа с локальным тестовым репозиторием.
- `render.py` — экспорт графа в DOT и создание изображения с помощью Graphviz.

### 5.1. Принцип работы

Общий алгоритм работы программы:

1. Пользователь запускает приложение из командной строки.
2. Программа получает параметры из YAML-файла и аргументов CLI.
3. В зависимости от режима работы загружаются данные из настоящего APKINDEX или локального тестового репозитория.
4. Формируется структура данных, представляющая зависимости пакетов.
5. Для выбранного пакета строится граф зависимостей.
6. При необходимости выполняется фильтрация или поиск обратных зависимостей.
7. Результат выводится в консоль.
8. Граф сохраняется в формате DOT и преобразуется в изображение PNG.

## 6. Этапы выполнения работы

### Этап 1. Разработка CLI-интерфейса и YAML-конфигурации

На первом этапе был разработан интерфейс командной строки, обеспечивающий взаимодействие пользователя с программой.

Реализовано:
- получение имени анализируемого пакета;
- чтение параметров из YAML-файла;
- настройка адреса репозитория;
- выбор тестового или реального режима;
- указание версии пакета;
- настройка фильтрации;
- указание директории для сохранения результатов;
- обработка ошибок конфигурации.

Для запуска программы предусмотрена возможность указать конфигурационный файл и дополнительные аргументы командной строки.

### Этап 2. Получение зависимостей из APKINDEX

На втором этапе реализована работа с метаданными репозитория Alpine Linux.

Программа получает файл APKINDEX из указанного репозитория и самостоятельно обрабатывает его содержимое.

Из записей извлекаются сведения о пакетах, включая:
- имя пакета;
- версию;
- список прямых зависимостей.

После обработки формируется структура данных, в которой каждому пакету соответствует список его зависимостей.

Такой подход позволяет получать информацию непосредственно из репозитория, не используя готовый пакетный менеджер для извлечения зависимостей.

### Этап 3. Построение графа зависимостей

На третьем этапе реализовано построение ориентированного графа зависимостей.

В графе:
- вершины соответствуют пакетам;
- направленные рёбра показывают зависимость одного пакета от другого.

Например, если пакет `curl` зависит от `libcurl`, `musl` и `zlib`, в графе создаются соответствующие направленные рёбра.

Для поиска транзитивных зависимостей применяется алгоритм обхода в ширину (BFS).

При обходе используется структура данных для хранения уже посещённых вершин. Это предотвращает повторную обработку пакетов и защищает алгоритм от зацикливания при наличии циклических связей.

Также реализована фильтрация пакетов по заданной подстроке.

### Этап 4. Поиск обратных зависимостей

На четвёртом этапе реализован поиск обратных зависимостей.

Обратные зависимости позволяют определить, какие пакеты используют выбранный пакет в качестве зависимости.

Например, если пакет `A` зависит от пакета `B`, то при анализе обратных зависимостей пакета `B` пакет `A` будет найден как зависимый от него.

Для этого анализируются связи между пакетами и формируется обратное представление графа.

Результат позволяет оценить, какие другие пакеты могут быть затронуты при изменении или удалении выбранного пакета.

### Этап 5. Экспорт и визуализация графа

На пятом этапе реализовано сохранение графа в формате DOT и его визуализация.

Файл DOT содержит описание вершин и направленных рёбер графа.

Для преобразования DOT-файла в графическое изображение используется Graphviz.

В результате работы программы формируются:
- файл `dependencies.dot` — описание графа;
- файл `dependencies.png` — изображение графа.

Полученные изображения позволяют наглядно изучать структуру зависимостей пакетов.

Также предусмотрена возможность сохранить граф без создания изображения.

## 7. Конфигурационный файл

Для настройки программы используется файл `config.yaml`.

Пример конфигурации:

```yaml
package_name: "curl"
repository_url: "https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64"
test_repository: false
package_version: "8.14.1-r4"
filter_substring: ""
test_repository_path: "test_data/repository.txt"
output_dir: "output"
graph_format: "png"
```

Описание параметров:

| Параметр | Назначение |
|---|---|
| `package_name` | Имя анализируемого пакета |
| `repository_url` | Адрес репозитория Alpine Linux |
| `test_repository` | Переключение тестового режима |
| `package_version` | Версия анализируемого пакета |
| `filter_substring` | Подстрока для фильтрации |
| `test_repository_path` | Путь к локальному тестовому файлу |
| `output_dir` | Директория для сохранения результатов |
| `graph_format` | Формат изображения графа |

## 8. Аргументы командной строки

Программа поддерживает следующие аргументы:

| Аргумент | Назначение |
|---|---|
| `--help` | Вывод справки |
| `--config` | Указание YAML-файла конфигурации |
| `--package` | Выбор пакета для анализа |
| `--direct-only` | Вывод только прямых зависимостей |
| `--reverse` | Анализ обратных зависимостей |
| `--dot-only` | Создание DOT-файла без генерации изображения |

Примеры запуска:

```powershell
# Просмотр справки
py -m src.main --help

# Обычный анализ
py -m src.main --config config.yaml

# Анализ другого пакета
py -m src.main --config config.yaml --package nginx

# Вывод только прямых зависимостей
py -m src.main --config config.yaml --direct-only

# Поиск обратных зависимостей
py -m src.main --config config.yaml --reverse

# Экспорт только в DOT
py -m src.main --config config.yaml --dot-only
```

## 9. Тестирование программы

Для проверки корректности работы программы предусмотрено модульное тестирование с использованием стандартного модуля `unittest`.

Тесты проверяют основные компоненты приложения:
- обработку конфигурации;
- получение и обработку данных о пакетах;
- построение графа;
- обход графа в ширину;
- фильтрацию зависимостей;

- формирование DOT-файлов;
- обработку ошибок.

Для запуска тестов используется команда:

```powershell
py -m unittest discover -s tests -v
```

Для проверки фильтрации использовался параметр:


Например, для пакета `curl` в графе оставалась связь с `musl`, а пакеты `libcurl` и `zlib` исключались.

## 11. Установка и запуск

### 11.1. Требования

Для работы программы необходимы:
- Python 3;
- библиотека PyYAML;
- Graphviz (для создания изображений);
- доступ к интернету для загрузки APKINDEX из реального репозитория.

Docker для обычной работы программы не требуется.

### 11.2. Установка зависимости

Установка PyYAML:

```powershell
py -m pip install PyYAML
```

Graphviz необходимо установить отдельно и добавить его исполняемый файл `dot.exe` в переменную среды `PATH`.

Проверка установки:

```powershell
dot -V
```

### 11.3. Запуск

Перейдите в корневую директорию проекта:

```powershell
cd practica-2
```

Запустите программу:

```powershell
py -m src.main --config config.yaml
```

После завершения анализа результаты будут сохранены в директории, указанной в конфигурации.
